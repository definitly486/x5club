# X5 Покупки

Простое Android-приложение для просмотра истории покупок из личного кабинета [X5 Club](https://x5club.ru).

## Возможности

- Авторизация через WebView (логин на сайте)
- Автоматическое получение cookies
- Выбор периода: 7 / 30 / 60 / 90 / 180 дней
- Загрузка истории покупок (чеки + товары)
- Отображение списка чеков с суммами и составом
- Экспорт покупок в CSV (папка Downloads)
- Кнопка «Выйти» — очистка сессии

## Требования

- Android 8.0+ (API 26)
- JDK 17
- Android SDK 34

## Сборка

```bash
# Debug APK
./gradlew assembleDebug

# Результат:
# app/build/outputs/apk/debug/app-debug.apk
```

## Использование

1. Установите APK
2. Откройте приложение → откроется сайт X5 Club
3. Войдите в свой аккаунт
4. Нажмите кнопку **«Я вошёл — загрузить покупки»**
5. Приложение загрузит чеки за последние 60 дней

## GitHub Actions

При пуше в `main`/`master` автоматически собирается debug-APK и выкладывается как артефакт.

## Важно

- Cookies имеют ограниченный срок жизни. Если история перестала загружаться — просто войдите заново.
- Приложение не хранит логин/пароль, только cookies сессии.
- Формат ответа сайта может измениться — тогда потребуется обновить парсер `TurboStreamDecoder`.
